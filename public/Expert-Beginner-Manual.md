# Expert Application - Beginner's Guide

## Quick Start Guide

### What is Expert?
Expert is an AI-powered writing assistant that helps you create long documents like novels, manuals, reports, and more. Think of it as having a smart writing partner that helps you organize ideas, generate content, and improve your writing.

### First Time Setup
1. **Enter your Expert application key** when prompted
2. **Click ⚙️ Settings** and add your OpenRouter API key
3. **Test the connection** - you should see a green checkmark
4. **Select AI models** - GPT-4 or Claude-3 work great for beginners
5. **Create your first project!**

---

## Creating Your First Project

### AI-Powered Project Creation (Recommended)
1. Click **📝 New Project**
2. Select the **"AI"** tab  
3. Describe what you want: "A fantasy novel about a young wizard"
4. Let the AI create the complete structure for you!

### Manual Project Creation
1. Click **📝 New Project**
2. Select **"Manual"** tab
3. Choose a template (Novel, Technical Manual, Business Plan, etc.)
4. Give it a title and click **Create**

---

## Working with Your Project

### The Project Tree
On the left, you'll see your project organized like folders:
- 📁 **Book** (main project)
  - 📄 **Chapter 1** 
  - 📄 **Chapter 2**
  - 📄 **Character Sheets**

### Basic Actions
- **Click any item** to select and edit it
- **Right-click** for more options
- **Changes save automatically**

### Generate Content with AI
1. **Select a chapter or section**
2. **Click ⚡ Generate** 
3. **Wait for AI** to create content
4. **Edit as needed**

---

## Node Chat - Talk to Your Project

**This is Expert's most powerful feature for beginners!**

### How to Start a Chat
1. **Right-click** any item in your project tree
2. **Click "💬 Chat"**
3. **Choose scope**:
   - This node only
   - Include children (recommended)
   - Multiple levels deep

### What You Can Ask
- **Get writing help**: "How can I make this chapter more exciting?"
- **Brainstorm**: "What should happen next in my story?"
- **Check consistency**: "Does this match my character's personality?"
- **Plan ahead**: "What are some good plot twists?"
- **Fix problems**: "This dialogue feels unnatural, help me improve it"

### Example Chat
**You**: "This chapter feels boring. How can I make it more engaging?"

**AI**: "Looking at your tavern scene, try adding:
1. A mysterious stranger who overhears the conversation
2. Someone recognizes your hero from their past  
3. A bar fight that reveals character personalities..."

---

### What the AI Can Change (User Guide)

- Outline: the overall structure and flow of your project.
- Sections: optional headings for Acts/Chapters only (e.g., `===Act I===`, `===Chapter 1===`).
- Context items: short facts like characters, locations, and themes.

Tips:
- Ask clearly: "Improve `===Chapter 2===` by raising the stakes."
- Keep triggers short for context items (names/keywords only).
- Complex activation rules for context must be edited manually.

## Essential Tools for Beginners

### Polish Your Text
When you have content that needs improvement:
1. **Right-click** on any content
2. **Select "🎨 Polish Text"**
3. **Tell AI what you want**: "Make this more formal" or "Fix grammar"
4. **Apply the improvements you like**

### Reader View (📖)
- **Clean reading interface** without distractions
- **Click any text** to see AI improvement options
- **Print or export** your finished work
- **Navigate with table of contents**

### AI Text Editing
In Reader View, select any text to see options:
- **Rewrite**: Improve the text
- **Expand**: Add more detail  
- **Simplify**: Make it clearer
- **Change tone**: Make it formal/casual

## Troubleshooting

### AI Not Working?
- **Check OpenRouter API key** in Settings
- **Make sure you have credits** in your OpenRouter account
- **Test connection** should show green checkmark

### Generation Too Slow?
- **Use faster models** like GPT-3.5
- **Reduce context size** in Node Chat
- **Check internet connection**

### AI Doesn't Understand Your Project?
- **Use Node Chat** to explain what you want
- **Add character sheets** and project descriptions
- **Be more specific** in your requests

---

## Quick Tips for Success

1. **Start small** - create a simple project first
2. **Use Node Chat liberally** - it's your best learning tool
3. **Don't worry about perfect settings** - defaults work well
4. **Export your work** regularly as backup
5. **Experiment!** - the AI gets better as you use it more

### Making AI Work Better
- **Be specific**: "Write tense dialogue" vs "Write dialogue"
- **Give context**: Tell the AI about your story/project
- **Use examples**: Show the style you want
- **Iterate**: Generate, review, improve, repeat

## Common Workflows

### For Fiction Writers
1. **Chat about your story idea** to brainstorm
2. **Generate chapter outlines** 
3. **Create character sheets**
4. **Generate scene content**
5. **Polish and refine** in Reader View

### For Non-Fiction
1. **Chat about your topic** to organize ideas
2. **Generate section outlines**
3. **Create detailed content** for each section
4. **Use Polish Text** to improve clarity
5. **Export** your finished document
